## :globe_with_meridians: Qiskit Global Summer School 2025 - Solutions
This repository contains **my personal solutions** for the labs of the [Qiskit Global Summer School 2025](https://www.ibm.com/quantum/blog/qiskit-summer-school-2025).  

The original [lab materials](https://github.com/qiskit-community/qgss-2025) (notebooks, exercises, data) are provided by the Qiskit community under the Apache 2.0 license.

## :rocket: Lab Overview
### :white_check_mark: Lab 0: Hello Quantum World
This lab introduces the basics of using **Qiskit** for quantum computing.

**Key Topics:**
* Installation and setup of **Qiskit**
* Basics of quantum gates and circuits

**Exercises:**
* Design a GHZ state
* Transpile a GHZ state
* **Bonus:** Run GHZ on real quantum hardware

### :white_check_mark: Lab 1: Recreating Famous Experiments at Home
This lab focuses on recreating key quantum phenomena using **Qiskit**.

**Key Topics:**
* Superposition and Interference
* Quantum Measurement
* Entanglement

**Exercises:**
* Build a quantum circuit for the double-slit experiment
* Create and test a Schrödinger's cat circuit
* Construct a double-slit circuit with a path detector
* Construct and analyze a quantum circuit for the CHSH Game
* Build a quantum teleportation circuit
* **Bonus:** Run teleportation on real quantum hardware

### :white_check_mark: Lab 2: Cutting Through the Noise
This lab is about quantum noise, transpilation, and error mitigation techniques.

**Key Topics:**
* Identification and sources of quantum noise
* Quantum Approximate Optimization Algorithm (QAOA)
* Graph-to-Hamiltonian mapping
* Transpiler-based circuit optimization
* Zero Noise Extrapolation (ZNE) 

**Exercises:**
* Find the best qubits
* Convert graph problems to Ising Hamiltonian
* Calculate total circuit error on different backends
* Find qubit layouts with minimal two-qubit gate errors
* Use transpiler for optimal circuit layout
* Implement global and local folding on quantum circuits
* **Bonus:** Run the Max-cut problem on real quantum hardware

### :white_check_mark: Lab 3: Creating Good Results Together
This lab focuses on the simulation of quantum chemical systems.

**Key Topics:**
* Variational Quantum Eigensolver (VQE)
* Sample-based Quantum Diagonalization (SQD)
* Local Unitary Cluster Jastrow (LUCJ) ansatz

**Exercises:**
* Calculate the size of the O₂ Hamiltonian
* Flip a bit by configuration recovery
* Change the basis set of molecules
* Select the best initial qubit layout
* Add more interaction to LUCJ ansatz

### :white_check_mark: Lab 4: Toward Fault-Tolerance
This lab covers classical and quantum error correction.

**Key Topics:**
* Classical Error Correction
* Quantum Error Correction
* Advanced Quantum Error Correction

**Exercises:**
* Build a lookup table decoder for the 3‑qubit bit‑flip code
* Create a lookup table for a Steane code
* Detect errors using a lookup table
* Find the parity check matrices of the toric and gross codes
* Count the number of logical qubits for toric and gross codes
